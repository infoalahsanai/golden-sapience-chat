# Golden Sapience Chat

Sapience AI এই নামে আমাকে একটা শক্তিশালী মেগা শক্তিশালী মেগা শক্তিশালী এআই বানিয়ে দিতে হবে এটা কোন সাধারণ চ্যাট বট হবে না সরাসরি ইন্টারনেটের সাথে কানেকশন থাকবে মানে মানুষের মত সবকিছু বুঝবে আমি আবারো বলছি এটা কোন চ্যাটবট হবে না তবে মেগা শক্তিশালী এটার পিছনে লক্ষ লক্ষ ডাটাবেজ থাকবে । এটার প্রধান বৈশিষ্ট্য হবে এটা Google Gemini API Key ওপেন রাউটার এপিআই কি groq API Key চলবে এবং এগুলোর মডেল আপনি অনলাইন থেকে নিশ্চিত হয়ে সেগুলো ড্রপডাউনে দিয়ে দিবেন। আর একটা কথা মনে করে দিচ্ছি, এটার প্রধান কাজ হবে মানুষের মতো আচরণ সবকিছু বুঝবে এ টু জেড । এটা দ্বিতীয় বৈশিষ্ট্যটা এপিআই কি দিয়ে চলবে। এটার থিম ডিজাইন অনেক প্রফেশনাল এবং সুন্দর করে যাতে খারাপ না দেখা যায় এবং সুন্দর দেখা যায় এরকম করে কাজ শুরু করে।
